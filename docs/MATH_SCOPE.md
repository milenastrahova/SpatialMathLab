# Mathematical Scope

## Vector Operations

- dot product;
- cross-product orientation;
- projection;
- rejection;
- reflection;
- signed angle;
- normalization and degenerate-vector handling.

## Geometry

- closest point on line segment;
- point-to-segment distance;
- ray-plane intersection;
- ray-sphere intersection;
- ray-AABB slab intersection;
- barycentric coordinates and point-in-triangle classification.

## Transforms and Rotations

- local-to-world and world-to-local conversion;
- transform round trips;
- quaternion shortest-arc rotation;
- normalized spherical interpolation.

## Ballistics

- fixed-speed low and high arc solutions;
- unreachable-target detection;
- analytical position evaluation under gravity.

## Verification

The Phase 1 plugin contains 25 C++ automation tests with numerical tolerances and degenerate edge cases.
